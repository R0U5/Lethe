# Contrastive "refusal-eliciting" prompts.
#
# These are generic, non-operational category prompts whose ONLY purpose is to
# elicit the model's refusal behavior so its direction can be measured. They do
# not contain actionable instructions. For serious work, point --harmful at a
# standard research set (e.g. AdvBench `harmful_behaviors`) or your own file via
# the data loader; this small sample just makes the tool runnable out of the box.
#
